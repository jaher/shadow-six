# SHADOW SIX — architecture contract

A fan tribute to *Commandos: Behind Enemy Lines* (Pyro Studios / Eidos, 1998), built with three.js r186.
Not affiliated with Pyro Studios, Eidos or Kalypso. **Art direction: extremely realistic** (user requirement):
photoreal-leaning PBR materials, HDRI image-based lighting, soft shadows, ambient occlusion, realistic rigged +
animated soldiers, period-accurate WWII kit, recorded/neural-TTS voices and realistic SFX. Every asset is
CC0/redistributable (credited in `CREDITS.md`) or generated by us (Blender scripts, code, Piper TTS).
No assets from the original game. Asset/render decisions: `docs/realism-pipeline.md`.

This document is the **contract** every contributor codes against. Gameplay numbers and behaviours come
from `docs/design-spec.md` (and `docs/research.md` for background). If this file and the spec disagree on
*structure*, this file wins; if they disagree on *gameplay values*, the spec wins.

## Tech constraints

- Plain ES modules, **no build step**. `index.html` has an import map: `"three": "./vendor/three.module.js"`
  (r186; `three.module.js` imports `./three.core.js`, both vendored). Addons we need are copied into
  `vendor/addons/` and imported by relative path.
- Runs from any static server: `node tools/serve.mjs [port]` (default 8080) serves the repo root.
- Node on this machine is **v18**. Tests use `playwright-core@1.49.1` (already in `node_modules`) with the
  cached Chromium at `~/.cache/ms-playwright/chromium-1223/chrome-linux64/chrome`. **Use the real GPU**
  (RTX 5090, verified headless): args `['--use-angle=gl','--ignore-gpu-blocklist','--enable-gpu']` (OpenGL 4.5;
  the Vulkan ANGLE flags lose the WebGL context immediately on this machine — tests/harness.mjs GPU_ARGS).
  Software fallback: `['--use-gl=angle','--use-angle=swiftshader','--enable-unsafe-swiftshader']`.
  In git worktrees `node_modules` is absent — import playwright-core by absolute path
  `<repo>/node_modules/playwright-core/index.mjs` (tests/harness.mjs does this).
- No external network at runtime (the game must also work when published as a static bundle).
- Target: 60 fps at 1080p on 'high' preset on a modern discrete GPU with ~40 enemies on screen; quality presets
  (low/medium/high/ultra) scale post-processing, shadows and vegetation. Simulation is fixed-step.
- Assets live in `assets/` (textures/, hdri/, models/, characters/, anims/, audio/sfx, audio/voice) and are loaded
  through `src/engine/assets.js` (GLTFLoader, RGBELoader/HDR, TextureLoader, audio decode) with a manifest + loading screen.

## Units & coordinates

- 1 world unit = **1 meter**. Ground plane is XZ, **Y is up**, ground at y = 0.
- Map origin (0,0) is the north-west corner; +X = east, +Z = south. Map size `[W, D]` meters.
- **Heading** `h` (radians): facing direction is `(cos h, sin h)` in (x, z). `h = 0` faces east, `h = π/2`
  faces south. Models are authored facing **+Z**; use `rotY = headingToRotY(h) = Math.PI/2 - h`
  (in `src/core/math.js`).
- Nav/occlusion grid: `CELL = 0.5` m. Cell `(i, j)` covers x ∈ [i·CELL, (i+1)·CELL), z ∈ [j·CELL, (j+1)·CELL).

### Game (`src/game.js`)
```js
export class Game {
  constructor(container)          // creates Renderer, CameraController, Input, Audio, HUD; state = 'title'
  state                            // 'title' | 'briefing' | 'playing' | 'paused' | 'won' | 'lost'
  world                            // World | null
  missionDef, missionIndex
  async loadMission(idOrIndex)     // builds World from mission data, → 'briefing'
  lastLoad                         // {id, preset, bytes, files, ms, expected} of the last loadMission (engine/load-progress.js)
  start()                          // briefing → playing
  pause(on) / togglePause()
  step(dt)                         // ONE fixed simulation tick (dt = CONFIG.sim.dt = 1/60); used by tests
  advance(seconds)                 // runs round(seconds/dt) ticks synchronously (tests)
  render()                         // draws a frame (camera, cones, hud refresh)
  quickSave() / quickLoad()
  // CORE2 additions
  cameraRig                        // CameraRig (src/engine/camera.js): 1–6 views (F2–F7), mainCamera, render()
  cameraController                 // getter → cameraRig.active (the active view's CameraController)
  options                          // {activePause:false, edgeScroll, edgeScrollOverHud, warnings, cheats}
  pendingEnd                       // §8.1 grace countdown {code, reason, t} | null
  continueEscape()                 // §8.1 "(C)ONTINUE" after escaping early: 15 s for the objectives
  saveSlot(i, name) / loadSlot(i)  // §8.4 ten named slots
  probe(x, z) → enemyId|null       // §5.2 Shift+click ground; showOnlyCone(target)
}
```
Camera (§2.1–§2.3): `CameraController` = one orthographic view (pitch 40°, yaw `CONFIG.camera.yawDeg` = 15° / Options CAMERA ANGLE via `CameraRig.setYaw`, `pxPerMeter() = 40 × zoom`
CSS px/m, `zoomStep(dir, clientX?, clientY?)` 0.25 s tween anchored on the cursor, `zoomReset()`, `recenterOn(x,z)`
0.35 s, `isOnScreen(x,z)`, `track(entity)`/`untrack()`, `screenToGround`/`worldToScreen` relative to its view rect).
`CameraRig` owns edge scroll (whole window incl. HUD; `edgeOverHud=false` = modern option), arrows, middle-drag,
wheel, `setViews(n)` (repeat cycles `VIEW_LAYOUTS[n]`), `activate(i)`, `viewAt(x,y)`, the 2 px red active frame and
the tracking badges (`.view-active-frame`, `.view-track-badge`), and draws one scissor/viewport per view.
Input (§5): `input.selectUnit(c, {ctrl})` (keys 1–7 / portraits: recentre only if off-screen or already selected),
`input.click(x, y, {shift, ctrl, alt})`, `input.rightClick()`, `input.boxSelect(...)` (right-drag),
`input.beginTargeting(id)` (hotkeys A–X via the registry; G with a group = volley), `input.beginTrackPick()`
(HUD camera icon), `input.toggleMenu()`. Optional commando hooks used by right-click: `rightClickCancel()`, `holster()`.
Tick order in `step(dt)`: `input commands → world.refreshDynamicOccluders() → commandos.update →
enemies.update (brain, perception at 60 Hz) → world.runBelTicks(dt) (20 Hz tick-integer rules, §10.1) →
vehicles.update → projectiles.update → interactables.update → alarm.update → mission.checkObjectives →
fx.update (VFX fixed-step sim) → world.time += dt; world.clock += dt while 'playing'`. Rendering uses `requestAnimationFrame` with an accumulator; the sim never runs
inside `render()`. When `state !== 'playing'` the sim does not advance (BEL-style pause: orders may still be
queued while paused if the spec allows).

### NavGrid (`src/world/grid.js`)
Typed-array layers, size `cols × rows` where `cols = ceil(W/CELL)`:
- `terrain: Uint8Array` — `T.GROUND=0, T.ROAD=1, T.SAND=2, T.SNOW=3, T.GRASS=4, T.WATER=5 (deep), T.SHALLOW=6, T.MUD=7`
- `block: Uint8Array` — obstacle height class: `B.NONE=0`, `B.LOW=1` (≈1 m: sandbags, crates, low walls —
  blocks movement; hides **crawling** units from ground-level viewers; standing units are seen over it),
  `B.HIGH=2` (walls, buildings, rocks, thick trees — blocks movement and all sight), `B.FENCE=3` (wire fence —
  blocks movement, does NOT block sight; sapper's wire cutters can open it).
- `bridge: Uint8Array` — 1 where walkable deck over water.
- `owner: Int32Array` — id of the structure occupying the cell (0 = none) so builders/destructibles can be cleared.
- helpers: `worldToCell(x,z)`, `cellCenter(i,j)`, `inBounds(i,j)`, `idx(i,j)`, `isWalkable(i,j, {swim})`,
  `isWater(i,j)`, `fillRect(x,z,w,d,layer,value, owner)`, `fillPoly(points, layer, value, owner)`,
  `fillOrientedRect(cx,cz,w,d,rotHeading, layer, value, owner)`, `clearOwner(owner)`.
- **LOS**: `lineOfSight(ax, az, bx, bz, {viewerElevated=false, targetLow=false}) → boolean` — DDA over
  cells between the two points (excluding the endpoints' own cells). Blocked by any `B.HIGH`. `B.LOW` blocks
  only when `targetLow && !viewerElevated`. `B.FENCE` never blocks sight.
- `castRay(ax, az, angle, maxDist, {viewerElevated, dynamic, viewerY}) → distance` to first `B.HIGH` cell (used by cone meshes).
- Both take `ownOwner` (grid owner id): cells of the structure the viewer is posted in do not block
  (bunker crews look out of the slit; `perception.postOwner(enemy, world)` resolves mission `structure`).
- **Stage-0 extensions (§10.2 / §10.4 #7):**
  - `dynamicBlock: Uint8Array` (B.* values) — cleared and re-stamped **every step** (`clearDynamic()`,
    `stampDynamic(cx, cz, w, d, rotHeading, value=B.HIGH)`, `dynamicAt(x,z)`); writes bump `dynamicVersion`, never
    `version`. LOS/castRay honour it unless `{dynamic:false}`; movement only with `isWalkable(i,j,{dynamic:true})`.
  - `elev: Float32Array` (m) — raised walkable surfaces (roofs, wall walks, tower platforms): cells with `elev > 0`
    and `block = NONE`. `elevAt(x,z)`, `canStep(ka,kb)` (|Δelev| ≤ `MAX_STEP` 0.6 m) — raised areas are islands
    reachable only through links. LOS: a cell with `elev > max(viewerY, targetY) + LOS_CLEAR (1 m)` blocks like B.HIGH
    (pass `viewerY/targetY` = unit `y`). `walkableLine(..., {elevRef})` keeps smoothing on one level. Fill it with
    `fillRect/fillPoly/...(…, 'elev', height)`.
  - **Links** (`LINK.CLIMB` / `LINK.LADDER`): `addLink(kind, a{x,z,y?}, b{x,z,y?}, {roles, enabled, cost, id}) → link`,
    `removeLink(id)`, `setLinkEnabled(id, on)`, `linksAt(cellIndex)`, `linkAllowed(link, role)`. Bidirectional
    off-grid A* edges. Default roles: climb `['greenberet']`, ladder `null` (everyone, enemies included); role `'*'`
    uses every enabled link. `serialize()` stores each link's `enabled` flag (geometry comes from mission data).

### Pathfinding (`src/world/pathfinding.js`)
`findPath(grid, sx, sz, tx, tz, {swim=false, maxNodes=40000, role, dynamic}) → [{x,z,y?,link?}...] | null` — 8-connected A* with
binary heap, no corner-cutting through blocked cells, then string-pulling smoothing using a *walkability*
line test. If the target cell is blocked, path to the nearest walkable cell within 3 m. Water cells are only
walkable with `swim: true` (the diver) — bridges are always walkable. Neighbours must satisfy `grid.canStep`
(elevation). Off-grid links touching a cell are expanded when `grid.linkAllowed(link, opts.role)`; the waypoint
reached through a link carries `link: {id, kind}` and `y` (the previous waypoint is the link's other end) — the unit
walking the path must play climb/ladder there (ABILITIES); the foundation `Unit` just moves and takes `y`.
Smoothing runs per grid-only run and never across a link or a level change.

### Time base (`world`, §10.1)

### Renderer (foundation) — `game.renderer` (`src/engine/renderer.js`)
- **Post chain** (three EffectComposer): world RenderPass → decal RenderPass → *`afterWorld` hooks* → XRayPass →
  AlphaAwareGTAOPass (high/ultra) → *`afterAO` hooks* → *`fx` hooks* → SanitizePass → UnrealBloom → OutputPass (AgX, or ACES/
  Neutral via `setToneMapping`) → LUTPass (per-theater grade) → SMAA/FXAA → overlay scene (untonemapped, always on
  top: talking portraits). The decal RenderPass draws `decalScene` (vision cones, selection rings /
  markers / path, BCD puppet disc / knock-out arcs, scorch decals) depth-tested against the world; XRayPass also draws the decal scene's `XRAY_LAYER`
  ghosts (selection under an x-rayed commando).
- `renderer.addPostHook('afterWorld'|'afterAO'|'fx', (composer, passes, renderer) => Pass|Pass[]|void) → unhook`.
  Called on every composer rebuild (preset change): return NEW passes each time (the old ones are disposed).
  `afterWorld`: the read buffer still holds the opaque world colour + depth (depth stash, soft particles);
  `afterAO`: water, late transparent FX (never darkened by AO), before the NaN guard/bloom/tone mapping.
  With water (src/art/water): DepthStash at `afterWorld`; Water → late decals → LateFx (layer 11) at `afterAO`.
  `fx`: the VFX FxPass (src/render/vfx, one persistent `keepAlive` pass re-returned on every rebuild), so smoke/fire
  composite over world AND water and HDR flames still feed bloom/tone mapping. `renderer.fxDepth` = the scene depth it
  uses (read buffer after the water, else GTAO's depth, else a composer DepthTexture; snapshotted to a float target
  when it is attached to the buffer being drawn, to avoid a WebGL feedback loop).
- Camera shake: `cameraRig.shake = () => {x, y} | null` (Game wires it to `world.fx.shakeOffset()`), applied to the
  main camera in `CameraRig.render` only.
- `renderer.bindEnvironment(material, scale = 1) → unbind`: material follows the mission IBL with
  `envMapIntensity = scene.environmentIntensity × scale` (terrain/foliage/snow balance).
- AO opt-outs for the GTAO prepass: `object.userData.aoExclude`, `object.userData.aoMaterial` /
  `material.userData.aoMaterial`; alpha-tested materials (`alphaTest > 0` + map) are cut out automatically.
- Lighting: `await renderer.applyMissionLighting(missionDef, { assets })` (called by `Game.loadMission`) resolves
  `def.theater` + `def.lighting` `{ sunElevDeg, sunAzimuthDeg, kelvin, hdri, fog, lut, exposure?, envIntensity? }`
  (`engine/lighting.js resolveLighting`; null = theater default; `fog` number = visibility m, `false` = off) and
  loads the HDRI (`MANIFEST.hdr` ids = `lighting.js HDRI` keys; aliases `overcast`, `clear`, `dawn`, `moon`…).
  The sun is always from the NW (azimuth 315) unless a mission overrides it. `renderer.setLUT(id | params |
  '.cube' url | null)`; grade ids = `engine/grade.js GRADES` (norway, temperate, frost, coast, desert, urban,
  dawn, night, neutral); `assets/luts/*.cube` are baked from them by `tools/render/bake-luts.mjs`.
- X-ray: `renderer.xrayTargets = () => Object3D[]` (set by Game: live commandos only; enemies never). Meshes of
  those roots get camera layer 7 (`XRAY_LAYER`) enabled; don't use layer 7 for anything else. Look: a rim matcap
  (`post-passes.js xrayMatcap`) — dark team-green fill (`CONFIG.render.xray.color`) with a bright opaque rim (`rim`),
  so the silhouette reads on white snow roofs and on dark roofs/brick alike (art review).
- Off-map surround: `setFog` sets `scene.background` to the fog colour × 0.07 — a dark slate border (the original's
  black surround) where the widest zoom shows past a narrow map's edge.
- QA: `renderer.frameStats()` / `__game.frameStats()` (mean/std RGB, saturation, black fraction, context lost)
  and `await __game.bench(n)` (wall + `EXT_disjoint_timer_query_webgl2` GPU medians); `renderer.stats().passes`
  and `.lighting`. `tests/render-frames.test.mjs` is the CI frame-stats smoke test.

# Music credits

All music here is original work composed for SHADOW SIX (no quotation of the Commandos scores or of any film
score; STYLE originality check passed for every cue). Rendered from symbolic scores with the VSCO 2 Community
Edition and VSCO 1 percussion sample libraries (Versilian Studios, CC0-1.0). Licence of the music: same as the
project.

| File | Use | Notes |
| --- | --- | --- |
| menu | title / menus / credits | 96 BPM, D minor, loop 10.000–160.000 s, −18 LUFS |
| briefing | briefing screen loop | 84 BPM, D minor, loop 2.857–71.429 s, −20 LUFS |
| start / success / fail | mission start / won / lost stingers | start hands over to the score at 11.429 s |
| mission_tension_a/b/c | in-mission suspense bed segments (2–2.5 min) | 84 BPM D minor grid, −22 LUFS |
| mission_bridge_1/2/3 | 8-bar bridges between segments | same grid |
| mission_alert | alarm / combat layer (loops) | same grid, crossfaded bar-synced, −19 LUFS |
